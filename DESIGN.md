# Enicharet account interface

## Direction

Bold and premium, as selected by the user. People use account forms on phones
and laptops in varied lighting, so restrained dark surfaces need high-contrast
text, large controls, and unambiguous feedback.

## Color

Restrained strategy: charcoal tinted neutrals and a warm gold action accent.
Use OKLCH values for surfaces, borders, text, and semantic error states.

## Typography

Existing Geist family. Strong page headings; familiar readable form labels.

## Layout and components

Single-column forms with persistent labels, useful autocomplete attributes,
phone and single-field OTP inputs, and inline error messages. Wider screens can use
an editorial introduction beside the form. Mobile stacks content naturally.
No decorative animation or image assets are needed for authentication.

## Interaction

Buttons expose pending and disabled states. Errors are announced accessibly.
Focus rings remain visible. Navigation uses real links, and logout is a button.
