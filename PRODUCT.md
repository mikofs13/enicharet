# Enicharet product context

## Register

product

## Users

People participating in lowest unique bid prize auctions, initially through a
responsive website. Administrators manage prizes, auction rules, and outcomes.

## Product Purpose

Users pay a fixed entry fee per bid. The lowest unique bidder receives a deadline
to pay their bid amount. Nonpayment excludes that user from that prize only and
advances to the next eligible unique bidder. No eligible bidder means fee refunds.
The project is being implemented in working stages, beginning with accounts.

## Accounts

The user requires phone-number accounts with an SMS OTP on every new login.
No email address or password is requested. First successful verification creates
an account; a cookie holds the session until it expires or the user logs out.

## Brand Personality

The user approved the Studio design preview on 2026-10-27: a crisp prize
marketplace with cobalt and apricot, confident typography, paired phone imagery,
and a light/dark theme system. Forms remain clear, direct, and trustworthy.

## Anti-references

No specific anti-references have been supplied.

## Design Principles

- Make the current task and next action clear.
- Show only implemented functionality; label test money clearly and do not imply
  live payments, bid submission, or settlement work before implementation.
- Keep money, payment deadlines, and user permissions explicit.
- Use a consistent responsive interface for desktop and mobile browsers.
- Support Light, Dark, and System appearance with a saved device preference.

## Accessibility & Inclusion

No additional user-specific accessibility requirements have been supplied.
Implementation baseline: semantic labels, keyboard access, visible focus states,
readable contrast, status announcements, and reduced-motion support.
